# Skill: Search Knowledge Base

**Используется**: Всеми агентами
**Когда**: Нужно сослаться на SAP-факт, EPAM-кейс, прайс, отраслевую специфику

## Что делает

Ищет релевантную информацию в локальной базе знаний (`knowledge/`).

## Где искать (по типу запроса)

| Тип запроса | Куда смотреть |
|---|---|
| SAP-модули, функциональность | `knowledge/sap-products/` |
| Прошлые кейсы EPAM | `knowledge/case-studies/` |
| Прайсы, rate cards | `knowledge/pricing-guides/` |
| Отраслевая специфика | `knowledge/industries/` |

## Алгоритм

### 1. Сначала — точный поиск
- Имя файла известно? Открой напрямую через `#file:...`
- Знаешь термин? Grep по содержимому: `#search:S/4HANA Cloud Private`

### 2. Если точный не дал — широкий
- Прочитай `README.md` в каждой подпапке `knowledge/`
- Найди наиболее релевантный файл по описанию
- Прочитай его целиком

### 3. Если в knowledge/ нет — честно скажи

**НЕ ВЫДУМЫВАЙ.** Если в knowledge/ нет информации:
- Скажи: "В нашей базе знаний нет данных по [теме]"
- Предложи: "Могу выдать общую гипотезу, но она требует проверки у эксперта"
- НЕ выдавай предположения за факты

## Правила цитирования

Когда используешь данные из knowledge/:
- Указывай источник: "По данным `knowledge/sap-products/s4hana-overview.md`, ..."
- Это даёт пользователю возможность проверить
- Это снижает риск галлюцинаций (если файла нет — увидишь)

## Анти-паттерны

❌ "S/4HANA Cloud Public поддерживает X" — без источника
✅ "Согласно `knowledge/sap-products/s4hana-cloud-public.md`, S/4HANA Cloud Public поддерживает X"

❌ "Обычно SAP-трансформации в банкинге занимают 18 мес"
✅ "По нашим прошлым проектам в banking (`knowledge/case-studies/banking-*.md`), типичный срок — 18-30 мес"
