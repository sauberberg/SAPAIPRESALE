# SAPAIPRESALE

AI-driven multi-agent framework для пре-сейлс активностей по SAP проектам.
Вдохновлено архитектурой [BMAD-METHOD](https://github.com/bmad-code-org/BMAD-METHOD).

## Структура

```
src/
├── presales-skills/      # Лайфсайкл пре-сейлса (по стадиям)
│   ├── 1-discovery/
│   ├── 2-solution-design/
│   ├── 3-estimation-pricing/
│   ├── 4-proposal/
│   └── 5-demo-poc/
├── core-skills/          # Cross-cutting скиллы (help, brainstorming, review)
├── agents/               # Персоны агентов (Solution Architect, Proposal Writer и т.д.)
├── templates/            # Шаблоны RFP-ответов, blueprint'ов, estimation sheets
├── knowledge-base/       # База знаний по SAP продуктам (S/4HANA, SF, Ariba, BTP)
└── scripts/
```

## Статус

Skeleton — только структура папок.
